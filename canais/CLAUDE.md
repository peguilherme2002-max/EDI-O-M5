# canais/ — estrutura e isolamento
- Cada canal tem pasta própria em canais/<canal>/; tudo o que é dele fica ali:
  ficha.yaml, CLAUDE.md, padroes_referencia.md, regras/, templates/, catalogo/, assets/, roteiros/, relatorios/, entrega/.
- Canal novo só por decisão de Pedro (F05). Abertura (doc 9.2): A1 Pedro decide → A2 Claude Code cria pasta, ficha e CLAUDE.md por ordem dele → A3 Fase 0 → A4 piloto curto em formato longo.
- Isolamento: um canal não lê nem usa catálogo, regras ou assets de outro sem decisão de Pedro (F17).
- canais/_amostras/ não é canal: serve só às amostras da construção (9.1), com kit neutro provisório. F18 não se aplica a ele.
